# scala-publish

*Library to publish artifacts to Maven repositories*

Originally based on the [`publish` module](https://github.com/coursier/coursier/tree/c8a0a64bd913c3e54432d9133c2b76a85f4b708b/modules/publish)
of [coursier](https://github.com/coursier/coursier), then forked from [`coursier/publish`](https://github.com/coursier/publish).

Core dependency of [Scala CLI](https://github.com/VirtusLab/scala-cli), the official `scala` runner command.
